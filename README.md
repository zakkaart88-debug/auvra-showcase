## 可以做什么

| 你想做的事 | 在 AUVRA 中 |
| --- | --- |
| 选择合适的模型 | 按模型和服务渠道选择图片、视频、音频能力 |
| 使用自己的账户 | 连接自己的 API 密钥，也可连接自己的远程 ComfyUI |
| 把创作串起来 | 在画布中组织参考图、提示描述与生成结果 |
| 从图片拍到视频 | 使用模型支持的首帧、首尾帧或多参考模式 |
| 延续镜头 | 使用相机球、下一镜及视频截帧功能探索镜头 |
| 探索白模预演 | 使用实验性白模参考功能辅助运镜和空间创作 |

我们支持并鼓励使用官方 API，也提供部分第三方渠道供用户自行选择。模型能力、计费与可用性因渠道而异，以网站当前选项和供应商实际账单为准。

## 适合谁

想用多种模型探索影像的个人创作者、制作分镜与短片的创作团队，以及使用自有 API 或 ComfyUI 算力的 AI 影像爱好者。

## 开始体验

1. 打开 [auvra.art](https://auvra.art/)，注册或登录。
2. 在「API 接口」连接自己的服务账户，或设置远程 ComfyUI。
3. 新建项目，把参考素材放进画布，选择模型并开始创作。

无需在 GitHub 安装 AUVRA。生成费用由所选供应商收取；连接账户并不等于免费生成。
