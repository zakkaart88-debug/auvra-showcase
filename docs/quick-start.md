# 快速开始

## 先选择创作方式

打开 [AUVRA](https://auvra.art/)，注册或登录后新建项目。

- **云端模型**：在「API 接口」连接自己的供应商账户。不同渠道分别保存连接设置，选择模型时留意对应渠道。
- **自有 ComfyUI**：连接自己的远程实例。实例需要具备所选工作流需要的模型与依赖，按网站连接引导完成检查。

不需要把 API 密钥发给我们或贴在 GitHub。请只在网站对应的连接设置中输入。

## 做第一个镜头

1. 添加参考图片，或直接输入想创作的画面。
2. 选择图片或视频模型、渠道及页面可用的画幅、清晰度、时长。
3. 检查参考素材和费用提示，再提交生成。
4. 结果完成后在画布里查看、下载，或作为下一次创作的参考。

可以从一个短镜头开始，先确认素材、模型和结果符合需求，再增加复杂度。

## 常见问题

**需要订阅每一家模型平台吗？**

AUVRA 支持使用自己的 API 账户。供应商可能采用按量计费、预充值或其他计费方式，请核对所选服务的规则。

**为什么同一个模型有不同渠道？**

不同渠道的价格、能力、稳定性和隐私条款可能不同，用户自行选择。名称相似不代表所有接口能力一致。

**白模预演能精确还原三维场景吗？**

这是实验性参考功能，用于探索镜头与空间关系。生成模型可能重新理解参考，不承诺精确还原几何、动作或运镜。

**生成失败怎么办？**

先查看网站错误提示和供应商任务记录，避免反复新建同一任务。需要帮助时，通过网站「反馈」或本仓库 Issues 提供经过脱敏的说明。
